# MOTO CDMX 2026

Infografía jurídica interactiva sobre infracciones, facultades policiales y remisión de motocicletas al depósito vehicular en la Ciudad de México.

Información actualizada al 20 de septiembre de 2026.

## Consulta

- `index.html`: versión publicada mediante GitHub Pages.
- `moto_cdmx_legal_2026.html`: archivo autónomo para consulta sin conexión.
- `fuentes_legales.md`: fuentes oficiales consultadas.
- `matriz_juridica.csv`: matriz de conductas, sanciones, puntos y fundamentos de remisión.
